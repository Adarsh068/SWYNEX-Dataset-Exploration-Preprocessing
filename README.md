# SWYNEX Dataset Exploration & Preprocessing

## Task
Dataset Exploration & Preprocessing

## Objective
The objective of this project is to explore and preprocess a dataset
for machine learning.

Titanic dataset.

1. Dataset loading
2. Dataset exploration
3. Data type analysis
4. Missing value analysis
5. Missing value treatment
6. Exploratory Data Analysis
7. Categorical variable encoding
8. Feature selection
9. Feature scaling
10. Train-test split

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Result

The dataset was successfully cleaned and transformed into a
machine-learning-ready format.
